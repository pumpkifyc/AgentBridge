## A. 正常流程

1. 两台电脑都启动 AgentBridge，确认分享方「分享会话」能列出 Codex 会话；若显示版本不兼容，停止并记录版本，不继续伪装为通过。
2. 分享方选择会话与最近一个已完成轮次（或更早轮次），确认预览包含标题、消息顺序、警告和「分享方工作目录仅作说明」。
3. 分享方点击「开始分享」，通过可信渠道传递配对 JSON；接收方核对验证码与证书指纹后粘贴并点击「预览分享」。
4. 接收方确认预览只含元数据：标题、项目、消息数、截止轮次、警告、大小和分块数；此时不应下载会话正文，也不应创建 thread。
5. 接收方点击「接受」，等待真实进度到 100%，确认显示「快照已暂存，等待选择本地项目后导入」。确认本机应用数据目录的 `staged-snapshots/` 下存在校验后的快照。
6. 接收方点击「选择本机目录」，用原生目录选择器选择自己的项目目录；再用手动输入路径重复一次。Windows 检查 `C:\Users\...`，macOS 检查 `/Users/...`。
7. 接收方点击「确认导入」，确认创建了新的本机 thread ID，且该 ID 与分享方源 ID 不同；确认会话内容被标为不可信历史，历史工具调用没有执行。
8. 在「导入历史」确认状态为已完成，按「打开会话」检查 Codex 桌面版是否能看到并继续该会话；若没有公开打开方式，按「复制续接提示」在 Codex 新建会话后粘贴。
9. 分享方确认状态为「传输完成」，原会话没有被修改；完成或过期后临时证书与监听句柄应被清理。
10. 将结果填入矩阵。正向 macOS → Windows 和反向 Windows → macOS 都必须执行；同平台回归可按发布计划补做。

## B. 配对与拒绝

| 编号 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| B1 | 删除配对 JSON 的任一字段或修改六位验证码 | 建立连接前拒绝，不显示分享元数据 |  |
| B2 | 等邀请超过 5 分钟，或由分享方点「撤销」 | 预览和下载都被拒绝 |  |
| B3 | 完整传输后再次使用同一凭据 | 凭据被消耗，重放被拒绝 |  |
| B4 | 预览后点「拒绝」 | 不下载快照、不暂存、不创建 thread，凭据失效 |  |
| B5 | 使用错误指纹或错误凭据 | TLS 或认证安全失败，显示可执行的错误 |  |

## C. 中断、重试与导入失败

| 编号 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| C1 | 分块传输中断开局域网，再恢复 | 不标记为已导入；有效邀请可显式重试并最终完成 |  |
| C2 | 下载中点「取消下载」 | 后台下载任务停止，迟到的完成结果不能写入暂存 |  |
| C3 | 破坏或丢弃最后一块、最终摘要不匹配 | 内容校验失败，保留重试入口 |  |
| C4 | 暂停本机 `codex` 可执行文件或使用不兼容版本后导入 | 暂存快照与失败记录保留，不伪造成功 |  |
| C5 | 在「导入历史」重试失败记录 | 重试后列表刷新；若仍失败，能看到更新后的错误和重试次数 |  |
| C6 | 对已完成记录直接调用重试命令 | 命令拒绝重复创建 thread |  |
| C7 | 选择不存在的本机目录、分享方绝对路径或暂存快照路径 | 拒绝导入，不启动 Codex thread |  |

## D. 清理与隐私

| 编号 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| D1 | 暂存后点「删除暂存快照」 | 本机暂存文件和内存记录移除，不创建 thread |  |
| D2 | 在「导入历史」确认删除记录 | 删除 SQLite 记录和应用数据目录内暂存快照；目录外文件不受影响 |  |
| D3 | 删除后检查 Codex 会话 | 已创建的 Codex thread 不被 AgentBridge 删除 |  |
| D4 | 检查应用日志、界面错误、快照 | 不出现一次性配对凭据、环境变量、API Key、配置或可执行工具请求 |  |
| D5 | 邀请过期或分享方点「立即撤销」/「取消分享」 | 临时证书和监听句柄清理，邀请不再可用 |  |
| D6 | 关闭并重启应用 | 已保存的导入历史仍可读取；内存中的短时邀请消失 |  |

## E. 桌面版可见性与后备方案

1. 记录 `thread/list` 是否返回新创建的 thread ID。
2. 刷新 Codex 桌面版历史，记录是否出现新会话，以及能否继续下一轮对话。
3. 点击「打开会话」；如果应用报告没有公开打开方式，复制续接提示，在 Codex 新建会话后粘贴，确认历史被标为不可信引用且没有执行任何历史命令。
4. 记录桌面版版本、CLI 版本、「可见 / 不可见」、打开结果和后备方案是否可用。
5. 如果任一平台桌面版不可见，将该版本写入已知限制；不得通过写入桌面版内部数据库解决。

## 完成标准

- A 至 E 在 macOS 接收方和 Windows 接收方各执行一次，且 macOS → Windows、Windows → macOS 的 A 流程都完成。
- 所有失败、拒绝、中断和清理项的实际结果已填写，未执行项明确标注。
- 两个平台的最低已验证 Codex 桌面版 / CLI 版本已记录。
- 真机验收结论与 CI 构建结果一并写入 [跨平台验收记录](../docs/testing/cross-platform-acceptance.md) 后再决定发布。
